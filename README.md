# Personal Portfolio Website

A personal portfolio website developed using C# and ASP.NET Core MVC to introduce personal information, skills, experience, and projects.

## Features
- Personal introduction and homepage.
- About Me section.
- Resume and experience information.
- Project portfolio.
- Services section.
- Contact page.
- Responsive web interface.

## Technologies
- C#
- ASP.NET Core MVC
- HTML
- CSS
- JavaScript
- Bootstrap
- Entity Framework Core

## Project Structure
- Controllers: Handles application requests.
- Models: Contains application data models.
- Views: Contains Razor pages and user interface.
- Migrations: Database migration files.
- wwwroot: Static files such as CSS, JavaScript, images, and libraries.

## Türkçe Açıklama

Bu proje, kişisel bilgilerimi, yeteneklerimi, deneyimlerimi ve projelerimi tanıtmak amacıyla geliştirdiğim kişisel portfolyo web sitesidir. ASP.NET Core MVC mimarisi kullanılarak oluşturulmuştur. Ana sayfa, hakkımda, özgeçmiş, projelerim, sunulan hizmetler ve iletişim bölümlerini içermektedir.
